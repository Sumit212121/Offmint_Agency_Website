# Aurelia Creative Studio Frontend

React + Vite frontend scaffold.

## Run locally
1. Install Node.js (if not already installed).
2. Open a terminal in this `frontend` folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Structure
- `src/main.jsx`: React entry point
- `src/App.jsx`: page composition
- `src/components/`: reusable UI components
- `src/sections/`: page sections
- `src/index.css`: global styles and CSS-based motion visuals

The six visuals are CSS-animated concepts, not WebGL/Three.js scenes yet.
